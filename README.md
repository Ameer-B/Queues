# Queue — Introductory Implementation (C#)

A minimal, beginner-friendly implementation of a **Queue** in C#.  
This project demonstrates the basic behavior of a FIFO (First-In, First-Out) data structure.

---

## Features
- Enqueue items  
- Dequeue items  
- Peek at the front item  
- Check if the queue is empty  
- Simple, easy-to-read code structure

---

## Concept
A queue processes elements in the order they arrive:

**First In → First Out**

Queues are commonly used in:
- Task scheduling  
- Buffers  
- Request handling  
- Breadth-first search (BFS)

---

## Purpose
A small introductory project to understand how queues work and how to implement them from scratch.
